# Mobile Price Range Prediction 

A Machine Learning project that predicts mobile phone price ranges and estimated prices using Random Forest Classification and Regression.

### Technologies
- Python, Pandas, Scikit-learn
- Random Forest
- Streamlit
- Google Colab and GitHub

### Project Files
- `Mobile_Price_Range_Prediction.ipynb` — Model training
- `mobile_price_models_compressed.pkl` — Trained models
- `train.csv` — Dataset
- `app.py` — Web application
- `requirements.txt` — Dependencies

### Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

**Note:** Predictions are estimates and may differ from actual market prices.
